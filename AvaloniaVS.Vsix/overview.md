# AXAML Tools for Visual Studio

A community-maintained Visual Studio extension for [Avalonia](https://avaloniaui.net) apps, based on the MIT-licensed AvaloniaVS extension. This is **not** an official Avalonia product.

- XAML previewer for `.axaml` files
- XAML IntelliSense and error tagging
- Avalonia project and item templates
- Snippets

**Supported:** Visual Studio 2022 (17.14 and later) and Visual Studio 2026 (18.x), x64 and Arm64. Avalonia 11.x and 12.x.

This extension collects no usage data.
